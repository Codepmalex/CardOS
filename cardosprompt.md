Create an OS on the cardputer ADV. Upon booting up, the device will land on the homescreen. This screen will display the time, day, and date, a search bar, and a grid of apps, and the weather (Pulled from WIFI, must be completley free). The user can navigate through the apps using the arrow keys. The search bar will allow the user to search for apps, files, and folders, and open them. Apps that should come stock and should be prebaked into the OS should be a notes app, a calendar app, a calculator app, a gyro/compass app, a unit converter app, a weather app, a folders app (which will allow the user to navigate through the file system), a settings app (with options to change how everything inside the device works, such as color theme, brightness, screen timeout, what each side button does, LED settings, notifications for apps, etc. Its up to you, add a lot here). If the user wants to install more apps, they'll take the SD card out (Or put it in USB Mass storage mode inside another USB Mass Storage app that will also be prebaked in the OS), place a .bin file in the "apps" folder, and upon launching the app, the OS will create or use another partition of the cardputer to install that app to, and if the user wants to run it the OS will flash that file to the partition and restart and boot into that app. When the user wants to turn back to the home screen they can press the RST button, and the device should just boot back into CardOS. The Cardputer is currently connected as of now and is ready for you, but make sure to fully flash it stock, wipe any partitions, the SD card is wiped for you already with one BRUCE app. If it makes it eaiser for you, the OS can and should be able to be controlled by a computer so you or someone else can work it with a laptop.
